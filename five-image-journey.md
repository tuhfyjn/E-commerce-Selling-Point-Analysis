# Five-Image Decision Journey

## Image 1 — Click Image

### Shopper question
What is this, and is it worth clicking?

### Objective
Earn attention and entry.

### Must have
- obvious product identity
- one primary hook
- strong visual hierarchy
- category-appropriate visual style

### Avoid
- selling-point lists
- tiny product
- decorative background stealing attention
- long explanatory text

---

## Image 2 — Selling-Point Image

### Shopper question
Why choose this one?

### Objective
Explain the strongest buying logic.

### Four questions
1. What problem does it solve?
2. Where is it better or different?
3. What should the shopper remember?
4. What evidence supports it?

Use 3–5 supporting points only if they reinforce one central value.

---

## Image 3 — Detail / Quality Image

### Shopper question
Is it really well made?

### Objective
Make quality visible.

### Good evidence
- material
- texture
- seams
- joints
- thickness
- interface
- reinforcement
- structure
- safety details

Use:
`close-up + label + why it matters`

Do not use a close-up without interpretation.

---

## Image 4 — Specification / Scenario Image

### Shopper question
Will it fit me, my space, or my device?

### Objective
Create purchase certainty and reduce returns.

Show as relevant:
- dimensions
- weight
- capacity
- colors
- variants
- compatible devices
- user types
- usage scenarios

---

## Image 5 — Guarantee Image

### Shopper question
What happens if something goes wrong?

### Objective
Reverse perceived risk.

Possible elements:
- packaging protection
- shipping promise
- return policy
- warranty
- authenticity
- certification
- customer service
- repair / replacement policy

Use only real terms and clearly state conditions where needed.

---

## Sequencing rule

The actual order should follow the shopper’s biggest remaining doubt.

Examples:

### High trust-risk category
click → trust → value → detail → guarantee

### High compatibility-risk category
click → value → compatibility → detail → guarantee

### High visual-outcome category
click → scenario result → detail proof → specification → guarantee
