# Decision Framework

## 1. Core equation

Use this as a decision heuristic, not a literal mathematical model:

`main-image effectiveness ≈ instant clarity × need match × differentiation × visual proof × trust`

If any factor is near zero, the whole result weakens.

## 2. Two-stage diagnosis

### Search / feed stage

Ask why the shopper would not click:

- unclear product identity
- product too small
- no obvious benefit
- no differentiation
- cluttered information
- visual style mismatched to category
- weak contrast in a crowded result page

### Product-page stage

Ask why the shopper would not buy:

- unclear reason to choose this SKU
- insufficient evidence
- uncertain size / compatibility / fit
- quality concern
- performance skepticism
- high perceived risk
- unclear warranty or return terms
- price-value mismatch

## 3. Five-level value translation

### Level 1: Attribute

Examples:

- 5000mAh
- aluminum frame
- 18000Pa
- 304 stainless steel

### Level 2: Advantage

Examples:

- larger battery
- lighter body
- stronger suction
- corrosion-resistant material

### Level 3: User benefit

Examples:

- charge less often
- easier to carry
- removes hair faster
- easier to clean and maintain

### Level 4: Purchase reason

Examples:

- one charge can cover a whole trip
- a child can lift it independently
- pet hair can be cleaned in one pass
- daily wet use is less troublesome

### Level 5: Evidence

Examples:

- verified endurance test
- measured product weight
- suction test under defined conditions
- material certificate / spec sheet

A main-image headline should usually live at Level 3 or Level 4. Parameters normally support it at Level 5.

## 4. Purchase-reason ranking

Score each candidate from 1–5 on:

- user relevance
- competitor gap
- evidence quality
- visual proof potential
- comprehension speed

Use the top-scoring reason for image 1 unless a trust barrier is more urgent.

## 5. Single-image hierarchy

Recommended hierarchy:

1. primary hook
2. product
3. supporting evidence
4. optional transactional information

Avoid more than three competing pieces of attention.

## 6. Main-image failure patterns

Rework the strategy if any applies:

- shopper cannot identify the product quickly
- image 1 has 4+ competing selling points
- headline uses empty adjectives
- features are listed without user outcomes
- copy says one thing but the visual proves nothing
- composition is indistinguishable from most competitors
- unsupported numbers or certifications are used
- specification ambiguity can cause returns
- decorative design overpowers the product
