# Purchase Reason Ladder

Move from internal product language to shopper value.

## Ladder

1. Fact
2. Advantage
3. User outcome
4. Purchase reason
5. Evidence

Example:

```text
Fact: 5000mAh battery
Advantage: larger battery reserve
User outcome: fewer charges
Purchase reason: one trip without carrying a charger
Evidence: verified endurance test
```

## Ranking matrix

Score 1–5:

| Dimension | Question |
|---|---|
| Relevance | Does the target shopper strongly care? |
| Difference | Does it separate us from common competitors? |
| Evidence | Can we prove it? |
| Visualizability | Can we show it? |
| Speed | Can it be understood quickly? |

Use the highest total as the candidate for image 1.
