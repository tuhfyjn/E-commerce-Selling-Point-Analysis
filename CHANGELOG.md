# Changelog

## V1.1 — 2026-08-21

This release reorganizes the project into an original **8-layer Visual Conversion OS**.

### New architecture
1. Truth Layer — Product Truth Lock
2. Friction Layer — Decision Friction Map
3. Reason Layer — Purchase Reason Ladder
4. Hook Layer — Hook-to-Proof Pair
5. Proof Layer — No-Copy Proof Test
6. Journey Layer — Five-Frame Conversion Path
7. Consistency Layer — Product Identity Guard + Reference Style Genome + Gallery Rhythm Check
8. Experiment Layer — Score → Test → Learn

### New capabilities
- Product fidelity rules for AI-generated commerce images
- Reference-image style distillation without copying scenes
- Visual self-proof test with text hidden
- Gallery diversity/rhythm checks
- Platform constraint routing
- Updated V1.1 scoring rubric
- Updated machine-readable output contract
