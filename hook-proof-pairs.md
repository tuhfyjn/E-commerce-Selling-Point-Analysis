# Hook-to-Proof Pairs

A hook should never float without proof.

## Pairing table

| Hook | Best proof modes |
|---|---|
| Pain | before/after, scenario |
| Benefit | scenario, measurement |
| Contrast | fair side-by-side comparison |
| Scenario | action scene |
| Emotion | scene + rational support |
| Value bundle | multi-use visual |
| Trust | certification/service/authenticity evidence |
| Data | measurement or documented social proof |

## Formula

`Hook-to-Proof Pair = headline idea + visual action + evidence`

## Examples

### Lightweight
- Hook: 宝宝自己也能提
- Visual action: child lifting bicycle
- Evidence: measured weight

### Long endurance
- Hook: 一次充电，用很久
- Visual action: timeline / trip scenario
- Evidence: verified runtime

### Easy cleaning
- Hook: 毛发一遍清
- Visual action: visible clean path through debris
- Evidence: defined-condition demonstration
