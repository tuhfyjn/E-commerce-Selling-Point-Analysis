# ecommerce-main-image-strategy

**Current version: V1.1**

An original e-commerce visual conversion framework for AI Agents, operators, designers, and image-generation workflows.

## Positioning

This project is not a collection of image prompts.

It is a **Visual Conversion OS** that decides:

- what is true about the product
- why users do not click
- why users do not buy
- what purchase reason should lead
- how that reason should be visually proven
- how a 5-image set should move the shopper through the decision
- how to preserve product identity during AI generation
- how to distill reference style without copying
- how to score and A/B test the result

## V1.1 architecture

```text
Product Truth
    ↓
Decision Friction
    ↓
Purchase Reason
    ↓
Hook-to-Proof Pair
    ↓
Visual Self-Proof
    ↓
Five-Frame Conversion Path
    ↓
Identity + Style + Rhythm
    ↓
Score → Test → Learn
```

## Core idea

> A main image is a compressed purchase decision.

The default five-frame path is:

**Entry → Reason → Proof → Fit → Safety**

Equivalent business language:

**第1张卖点击，第2张卖理由，第3张卖证据，第4张卖确定性，第5张卖放心。**

## Original concepts in V1.1

- **Product Truth Lock** — prevent AI product drift
- **Decision Friction Map** — find the actual blocker
- **Purchase Reason Ladder** — translate facts into reasons to buy
- **Hook-to-Proof Pair** — every hook must have visual/evidence support
- **No-Copy Proof Test** — hide the text; the picture should still carry the idea
- **Reference Style Genome** — learn visual language, not exact scenes
- **Gallery Rhythm Check** — prevent five repeated poster layouts
- **Platform Constraint Router** — adapt strategy to marketplace rules
