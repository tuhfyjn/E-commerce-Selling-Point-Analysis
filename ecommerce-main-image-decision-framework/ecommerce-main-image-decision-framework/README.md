# 电商主图决策框架（E-commerce Main Image Decision Framework）

> 用“消费者决策顺序”而不是“美工排版顺序”设计电商主图。

本框架用于指导 AI Agent、运营、美工或产品团队，系统化完成电商主图的：
- 用户痛点识别
- 核心卖点提炼
- 购买理由转译
- 主图钩子选择
- 视觉证明设计
- 5 张主图排序
- 风险消除与信任构建
- 主图评分与 A/B 测试

## 一句话定义

**优秀的电商主图，是把消费者从“看到商品”带到“放心下单”的一套视觉销售路径。**

核心链路：

**吸引 → 说服 → 证明 → 解释 → 消除风险 → 下单**

## 核心公式

```text
主图效果 ≈ 一眼看懂 × 需求命中 × 差异感 × 视觉证明 × 信任感
```

单张图解决一个问题，整套图完成一次销售。

## 5 张主图默认决策链

| 图片 | 核心任务 | 用户脑中的问题 |
|---|---|---|
| 第 1 张：点击主图 | 抢点击 | 这是什么？值得点吗？ |
| 第 2 张：卖点主图 | 给购买理由 | 为什么选你？ |
| 第 3 张：细节主图 | 证明品质 | 真的有那么好吗？ |
| 第 4 张：规格/场景图 | 建立适配确定性 | 适合我吗？ |
| 第 5 张：保障主图 | 降低风险 | 买错/坏了/售后怎么办？ |

> 这不是死顺序。高风险食品、母婴、3C、高客单等类目可按用户真实决策阻力调整排序。

## 快速使用

1. 收集产品、用户、竞品和可验证证据。
2. 找到用户最大的“点击阻力”和“下单阻力”。
3. 把参数翻译成“用户结果”，再翻译成“购买理由”。
4. 为第 1 张选择一个最强钩子。
5. 用场景、对比、结构、数字、实测等方式把卖点可视化。
6. 按消费者决策顺序生成 5 张主图。
7. 用 100 分评分表打分。
8. 对低分项重做，并进行 A/B 测试。

## 核心原则

1. **卖点 ≠ 参数；卖点最终要变成购买理由。**
2. **人话做标题，参数做证据。**
3. **能用画面证明的，不只靠文字解释。**
4. **第 1 张不负责讲完产品，只负责让用户愿意点进来。**
5. **一张图只能有一个“视觉老板”。**
6. **主图不是凑够 5 张，而是一步步解决不下单的理由。**
7. **所有销量、认证、性能、处罚承诺、对比数据必须真实可证。**
