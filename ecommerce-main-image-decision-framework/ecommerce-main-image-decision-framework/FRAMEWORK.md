# 电商主图决策框架 v1.0

## 0. 目标

本框架的目标不是“把图做漂亮”，而是提升消费者决策效率：

```text
看到商品
  ↓
看懂商品
  ↓
产生兴趣
  ↓
理解购买理由
  ↓
相信购买理由
  ↓
确认适合自己
  ↓
降低购买风险
  ↓
下单
```

---

# 1. 输入层：先收集事实，不先想文案

至少收集以下 6 类信息。

## 1.1 产品事实

- 产品名称
- 类目
- 核心功能
- 关键参数
- 材质 / 工艺 / 结构
- 规格 / 型号 / 尺寸
- 使用场景
- 售后政策
- 可验证认证或测试

## 1.2 用户信息

- 核心目标人群
- 主要使用场景
- 最常见痛点
- 最大购买顾虑
- 最关注的结果
- 最容易理解的语言

## 1.3 竞品信息

至少看 5~20 个同搜索结果竞品：

- 大家都在讲什么
- 大家都长什么样
- 哪些卖点已经同质化
- 哪些信息被忽略
- 竞品弱点是什么
- 用户评论里反复出现的问题是什么

## 1.4 可验证证据

任何主图结论都应尽量有证据支持：

- 参数
- 实测
- 对比
- 认证
- 用户量 / 销量
- 售后条款
- 材质证明
- 结构说明

## 1.5 平台约束

- 淘宝 / 天猫 / 京东 / 拼多多 / Temu / Amazon 等
- 图片比例与尺寸
- 平台广告合规
- 类目特殊规则
- 是否允许促销信息、对比、绝对化表达等

## 1.6 商业目标

- 拉点击
- 提升转化
- 降低退货
- 打新品认知
- 打差异化
- 打高客单信任
- 清库存 / 促销

---

# 2. 决策层一：先判断用户为什么“不点”和“不买”

先回答两个问题。

## 2.1 点击阻力

用户在搜索结果页为什么不点你？

常见原因：

- 看不懂卖什么
- 主体太小
- 卖点模糊
- 跟竞品长得一样
- 没有利益点
- 视觉不醒目
- 风格与品类不匹配

## 2.2 下单阻力

用户点进来以后为什么不买？

常见原因：

- 不知道为什么选你
- 不相信你的卖点
- 不确定适不适合自己
- 担心质量
- 担心售后
- 担心尺寸 / 兼容
- 担心效果虚假
- 担心贵但不值

> 设计主图之前，必须先确定“最大阻力”。

---

# 3. 决策层二：把产品属性翻译成购买理由

使用 5 层价值转译法。

```text
属性 → 优势 → 用户利益 → 购买理由 → 证据
```

示例：

```text
5000mAh
→ 大容量电池
→ 更久不用充电
→ 出差一周也不用带充电器
→ 实测续航 30 天
```

再例如：

```text
铝合金车架
→ 车身更轻
→ 孩子更容易控制
→ 宝宝自己也能提起来
→ 净重 X kg / 场景实拍
```

## 判断标准

弱表达：

- 高品质
- 超耐用
- 大容量
- 强劲动力
- 多功能
- 舒适设计

强表达：

- 11 卷 660 撕，够用 3 年
- 洗头不湿眼
- 一打就通
- 宝宝自己也能提
- 一个月不用充电
- 打印机 + 学习机 + 错题机

---

# 4. 决策层三：选择主图钩子

一个主图只选一个主钩子。

## 4.1 痛点钩子

直接说用户最烦的事。

适合：
- 痛点明确
- 低理解成本
- 强需求类目

结构：

```text
痛点 → 解决结果
```

例：

```text
洗头不湿眼
剪厚甲不夹肉
养猫以后，地上也能没有毛
```

## 4.2 利益钩子

直接告诉用户买完得到什么。

结构：

```text
产品能力 → 用户结果
```

例：

```text
11 卷 660 撕，够用 3 年
一次充电，用 30 天
```

## 4.3 对比钩子

把“差距”视觉化。

结构：

```text
传统款 vs 升级款
使用前 vs 使用后
普通材质 vs 新材质
3 步 vs 1 步
```

## 4.4 场景钩子

让画面直接证明卖点。

例：

- 儿童抱起自行车 = 轻
- 产品泡水 = 防水
- 多人站上去 = 承重
- 放进口袋 = 便携

## 4.5 情绪钩子

用消费者语言而不是产品语言。

例：

```text
手感不会骗人
终于不用天天充电了
```

## 4.6 价值组合钩子

强调“一件顶多件”。

例：

```text
打印机 + 学习机 + 错题机
榨汁机 + 辅食机 + 研磨机
```

## 4.7 信任钩子

用户需求已经成立，但“不敢买”。

例：

```text
真材质
官方正品
可查认证
X 年质保
```

## 4.8 数据钩子

数据必须服务于以下之一：

- 性能
- 结果
- 信任

例：

```text
200 万人已买
累计销量破亿
18000Pa
30 天续航
```

---

# 5. 决策层四：选择视觉证明方式

优先级：

```text
画面证明 > 对比证明 > 数据证明 > 结构证明 > 文字描述
```

可选方式：

1. 使用场景
2. 前后对比
3. 新旧对比
4. 局部放大
5. 爆炸图 / 结构图
6. 实测
7. 数字
8. 认证 / 检测
9. 销量 / 用户量
10. 售后承诺

原则：

> 能演出来的卖点，就不要只写出来。

---

# 6. 单张主图结构

推荐采用 4 层信息结构。

## 第一层：主钩子

只放 1 个核心购买理由。

## 第二层：产品主体

产品必须明显、完整、易识别。

## 第三层：证据

最多 1~3 个辅助证据。

## 第四层：辅助成交信息

根据平台和类目选择：

- 官方
- 发货
- 赠品
- 质保
- 价格
- 活动

> 辅助信息不能抢主卖点。

---

# 7. 五张主图决策链

## 第 1 张：点击主图

### 用户问题

```text
这是什么？
值不值得点？
```

### 任务

- 一眼认出产品
- 一个最强钩子
- 视觉醒目
- 与竞品拉开差异

### 推荐结构

```text
主钩子
+
大产品主体
+
1~2 个证据
```

### 禁忌

- 5~10 个卖点堆满
- 产品主体过小
- 背景比产品抢眼
- 文案必须放大才能看懂

---

## 第 2 张：卖点主图

### 用户问题

```text
为什么选你？
```

### 任务

把核心优势讲成“购买理由”。

### 必答 4 问

1. 解决什么问题？
2. 比别人好在哪？
3. 最值得记住什么？
4. 凭什么相信？

推荐 3~5 个次级卖点，但必须围绕一个核心价值。

---

## 第 3 张：细节主图

### 用户问题

```text
真的做得好吗？
```

### 任务

让品质“看得见”。

可展示：

- 材质
- 接口
- 纹理
- 做工
- 厚度
- 结构
- 加固
- 缝线
- 安全设计

推荐：

```text
局部放大 + 标注 + 对用户的具体好处
```

不是只拍特写。

---

## 第 4 张：规格 / 场景主图

### 用户问题

```text
适合我吗？
```

### 任务

解决适配性与误购。

包括：

- 尺寸
- 重量
- 容量
- 型号
- 颜色
- 兼容设备
- 使用人群
- 使用场景

商业价值：

- 提升购买确定性
- 降低误购
- 降低退货

---

## 第 5 张：保障主图

### 用户问题

```text
买了出问题怎么办？
```

### 任务

风险逆转。

可使用：

- 包装保障
- 发货保障
- 售后保障
- 资质保障
- 正品保障
- 服务保障
- 质保周期
- 退换规则

核心表达：

```text
放心买，风险由商家承担。
```

---

# 8. 类目排序修正规则

默认 1→5 顺序并非固定。

## 食品 / 母婴

信任风险高：

```text
点击 → 信任/安全 → 核心卖点 → 细节 → 保障
```

## 数码 / 3C

参数决策强：

```text
点击 → 核心性能 → 规格兼容 → 细节 → 保障
```

## 高客单家具 / 家电

决策周期长：

```text
点击 → 核心价值 → 场景效果 → 材质细节 → 售后保障
```

## 低价快消

点击权重大：

```text
强钩子 → 结果 → 对比/证据 → 规格 → 活动/保障
```

# 9. 100 分主图评分模型

## 9.1 一眼识别：15 分

- 产品是什么是否清楚
- 产品主体是否足够明显
- 手机缩略图是否看得懂

## 9.2 钩子强度：15 分

- 是否有明确点击理由
- 是否能在 0.5~3 秒理解
- 是否能让用户停留

## 9.3 购买理由：20 分

- 是否从参数翻译到用户利益
- 是否击中真实需求
- 是否回答“为什么买”

## 9.4 差异化：15 分

- 是否与竞品明显不同
- 是否有对比或独特价值
- 是否避开同质化口号

## 9.5 视觉证明：15 分

- 画面是否在证明卖点
- 是否有场景 / 对比 / 结构 / 数据
- 是否减少纯文字说明

## 9.6 信息层级：10 分

- 是否只有一个视觉中心
- 主次是否明确
- 是否避免信息堆积

## 9.7 信任与合规：10 分

- 数据是否真实可证
- 认证是否真实
- 对比是否有依据
- 是否避免违规绝对化承诺

### 评分解释

```text
90~100：可直接进入 A/B 测试
80~89：较强，优化局部
70~79：能用，但点击/转化逻辑不够尖锐
60~69：偏“产品说明图”
<60：建议重做策略，不只是改美工
```

# 10. 硬性失败规则

命中任意一条，应优先重做：

- 用户 3 秒内看不懂卖什么
- 第 1 张同时争抢注意力的卖点超过 3 个
- 主标题只是“高品质 / 高端 / 新升级”等空泛词
- 卖点只有功能，没有用户利益
- 画面与文案互不证明
- 与主流竞品几乎同构图同文案
- 使用无法证明的销量、认证、性能、处罚承诺
- 规格信息模糊，容易导致误购
- 过度设计导致产品主体不清楚

# 11. AI Agent 决策流程

```text
START
  ↓
读取产品事实、用户、竞品、证据
  ↓
识别【最大点击阻力】
  ↓
识别【最大下单阻力】
  ↓
提取产品属性
  ↓
属性 → 优势 → 用户利益 → 购买理由
  ↓
筛选 Top 3 购买理由
  ↓
判断最强主钩子类型
  ├─ 痛点
  ├─ 利益
  ├─ 对比
  ├─ 场景
  ├─ 情绪
  ├─ 价值组合
  ├─ 信任
  └─ 数据
  ↓
为每个购买理由匹配视觉证明
  ↓
生成第 1 张点击主图
  ↓
生成 2~5 张决策链
  ↓
100 分评分
  ↓
是否 ≥ 85？
  ├─ 否 → 针对最低分维度重写
  └─ 是 → 输出 A/B 测试方案
```

---

# 12. 输出规范

Agent 最终不只输出“文案”，应至少输出：

1. 用户核心痛点
2. 最大点击阻力
3. 最大下单阻力
4. Top 3 购买理由
5. 第 1 张主钩子
6. 5 张主图各自任务
7. 每张主图文案
8. 每张主图构图建议
9. 视觉证明方式
10. 所需证据
11. 风险 / 合规提醒
12. 评分
13. A/B 测试变量

---

# 13. 最终检查清单

生成主图方案后，逐项问：

- [ ] 3 秒能看懂卖什么吗？
- [ ] 第 1 张只有一个核心购买理由吗？
- [ ] 标题是消费者语言，而不是产品参数吗？
- [ ] 卖点是否转译成用户结果？
- [ ] 与竞品相比，差异点明确吗？
- [ ] 画面是否在证明文案？
- [ ] 有没有能视觉化却只用文字写的卖点？
- [ ] 第 2 张解释了“为什么选你”吗？
- [ ] 第 3 张证明了品质吗？
- [ ] 第 4 张解决了适配与误购吗？
- [ ] 第 5 张降低了购买风险吗？
- [ ] 所有数据和承诺都能提供证据吗？
- [ ] 手机缩略图状态下仍然清楚吗？
- [ ] 是否有明确可执行的 A/B 测试变量？

---

# 14. 最核心的 8 句话

1. **主图不是设计问题，先是销售决策问题。**
2. **卖点不是写得越多越好，而是让用户快速理解价值。**
3. **卖点不是参数，购买理由才是卖点的最终形态。**
4. **人话做标题，参数做证据。**
5. **能用画面证明的，不只靠文字说。**
6. **一张图只有一个视觉老板。**
7. **第 1 张卖点击，第 2 张卖理由，第 3 张卖品质，第 4 张卖确定性，第 5 张卖放心。**
8. **不是凑够 5 张，而是一步步解决消费者不下单的理由。**
