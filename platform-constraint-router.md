# Platform Constraint Router

Before designing image 1, determine current platform requirements.

Check whether the platform permits:
- text overlays
- price/promotional copy
- badges
- lifestyle scenes
- props
- models
- comparison visuals
- logos/watermarks
- claims/awards

## Routing logic

```text
If image-1 text is restricted:
    move the hook into product presentation, angle, scale, or compliant visual proof.
If lifestyle is restricted:
    use compliant product-only proof.
If comparison claims are restricted:
    move comparison to allowed secondary assets or remove it.
```

Marketplace policies change. Verify current rules when the answer depends on them.
