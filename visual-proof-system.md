# Visual Proof System

## No-Copy Proof Test

Hide all copy.

Ask:

> Can the viewer still infer the core claim?

### Pass
The image itself carries the idea.

### Partial
The image suggests the idea but needs a clearer action, scale, or comparison.

### Fail
The image is decorative and the claim exists only in text.

## Proof modes

1. Scene proof
2. Comparison proof
3. Before/after proof
4. Measurement proof
5. Scale proof
6. Structural proof
7. Detail proof
8. Social proof
9. Service/risk proof

## Safety and truth

Do not create demonstrations that:
- imply unsupported performance
- use incomparable conditions
- hide failure cases
- require unsafe usage
- exaggerate scale deceptively
