# Hook and Visual-Proof Library

## Hook types

### 1. Pain hook

Use when the problem is vivid and already recognized.

Pattern:

`stop [pain]` or `solve [pain]`

Examples:
- 洗头不湿眼
- 厚甲也好剪
- 地上猫毛一遍清

### 2. Benefit hook

Use when the outcome is easy to value.

Pattern:

`[result] + [time / quantity / effort]`

Examples:
- 一次充电，用 30 天
- 11 卷 660 撕，够用 3 年

### 3. Contrast hook

Use when the gap is more persuasive than a standalone claim.

Patterns:
- traditional vs upgraded
- before vs after
- 3 steps vs 1 step
- ordinary structure vs new structure

The comparison must be fair and supportable.

### 4. Scenario hook

Use when the picture can prove the point faster than copy.

Examples:
- child lifting a bicycle = lightweight
- item fitting into a small bag = compact
- multiple travel items inside = capacity

### 5. Emotion hook

Use sparingly. It should map to a real product experience.

Example:
- 手感不会骗人

Pair emotional copy with rational proof.

### 6. Value-bundle hook

Use when one product credibly replaces several use cases.

Pattern:

`A + B + C`

Example:
- 打印机 + 学习机 + 错题机

Avoid implying functionality the product does not actually provide.

### 7. Trust hook

Use when the user already wants the category but fears being cheated or disappointed.

Examples:
- authentic material
- verified origin
- official warranty
- traceable certification

### 8. Data hook

Use only when the number is meaningful and evidenced.

Three useful roles:
- performance proof
- outcome proof
- social proof

## Visual-proof patterns

### Scene proof
Show the user outcome in context.

### Comparison proof
Show a clear, fair difference under comparable conditions.

### Detail proof
Use magnification, cutaway, labels, texture, structure, thickness, joinery, or interface details.

### Measurement proof
Use dimensions, weight, runtime, pressure, capacity, or other verified measurements.

### Social proof
Use genuine sales/user/award data only when documented.

### Risk proof
Show warranty, return conditions, certification, package protection, or service process.

## Copy rule

Use:

`human headline + concrete proof`

Prefer:
- “宝宝自己也能提” + measured weight

Over:
- “航空级铝合金轻量化升级”
